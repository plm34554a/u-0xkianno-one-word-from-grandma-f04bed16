The single word my grandma would text about AI: **robut** — her typo for "robot". Warm, a little baffled, and unmistakably about machines.

## How to run

```sh
python3 main.py
```

This writes exactly one word, with no trailing newline, to `/output/entry.txt` (creating `/output` if needed). Pure Python 3.13 standard library, deterministic — the same bytes on every run.
